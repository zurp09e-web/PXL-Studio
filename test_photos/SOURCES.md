# PXL high-resolution photo test set

Run `python download_test_photos.py` from the project root to fetch the
original-resolution JPEG test photographs into this folder. They are hosted
on Wikimedia Commons; attribution and licence details follow.

1. `rocky_mountains_rind.jpg` — 6000 × 4000, author Ավետիսյան91.
   https://commons.wikimedia.org/wiki/File:Landscape_in_the_rocky_mountains_of_Rind_06.jpg
   CC BY-SA 4.0.
2. `new_york_night.jpg` — 7360 × 4023, author chsyang.
   https://commons.wikimedia.org/wiki/File:New_York_City,_night.jpg
   Public Domain Mark, as recorded on the Commons file page.
3. `tatra_gubalowka.jpg` — 3264 × 2448, author Yair Haklai.
   https://commons.wikimedia.org/wiki/File:Tatra_mountains_view_from_Gubalowka_mountain.jpg
   CC BY-SA 4.0.

Retain this file and follow the licence terms when redistributing the photos.
